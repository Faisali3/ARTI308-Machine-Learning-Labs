# Logistic Regression Assignment

## Overview
This project applies Logistic Regression to predict whether a user clicks on an advertisement.

## Dataset
The dataset includes features like:
- Daily Time Spent on Site
- Age
- Area Income
- Daily Internet Usage
- Gender

## Steps Performed
1. Data Exploration
2. Visualization
3. Train/Test Split
4. Logistic Regression Model Training
5. Predictions
6. Evaluation using Confusion Matrix and Classification Report

## How to Run
1. Open the notebook
2. Run all cells
3. Ensure `advertising.csv` is in the same directory

## Output
The model outputs classification metrics to evaluate performance.
